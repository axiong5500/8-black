# 桌面图标台球 · Web 版

> 把桌面上的小图标摆成一局台球，打开浏览器就能打，不用安装、不用下载、不读你电脑里的任何文件。

这是一个纯网页版的休闲台球小游戏：白球在台面上滚动，把一颗颗带图标的球撞进四个角的袋子就算得分。玩法参考了桌面端项目 [desktop-icon-billiards](https://github.com/liuxiaogang-com/desktop-icon-billiards)，并用原生 HTML / CSS / JavaScript 重写成了单文件网页版本。

---

## 一分钟看懂这是什么

平时你电脑桌面上不是堆了一堆文件夹、浏览器、回收站的小图标嘛？这个游戏把这些"小图标"变成台球桌上的球，让你拿白球一杆一杆把它们撞进袋子里。

和传统台球一样：**瞄准 → 蓄力 → 松手击球 → 碰球、碰库反弹 → 入袋得分**。区别只是球上印的是文件夹、音乐、图片、相机这些日常图标。

- 打开就能玩，不装软件、不跑安装包
- 不读取你的真实桌面、不上传截图、不收集文件信息
- 手机、平板、电脑浏览器都能打开
- 代码就一个 `index.html`，想改想抄随便来

## 怎么下载和玩

### 方式一：直接在线玩（最省事）

如果你看到仓库里挂了 Pages / 在线演示链接，点链接即开即玩，什么都不用装。

### 方式二：下载到本地玩

1. 点仓库右上角的绿色 **Code** 按钮，选 **Download ZIP**，把压缩包下载下来；
2. 解压到任意文件夹；
3. 双击里面的 `index.html`，系统会用默认浏览器打开，直接开打。

> 不需要 Node、不需要 Python、不需要构建命令，也不用联网（打开页面后断网也能玩）。

### 操作说明（大白话版）

| 操作 | 怎么做 |
| --- | --- |
| 瞄准 | 移动鼠标，白球会跟着鼠标方向对准 |
| 蓄力 | **按住鼠标左键不松手**，旁边的力度条会涨，越按越用力 |
| 击球 | **松开左键**，白球就打出去了 |
| 看路线 | 白线是出球方向，蓝线是碰库/碰球后的方向，绿线是被撞图标大概会滚的方向 |
| 开关辅助线 | 点右下角「辅助线：开 / 关」 |
| 重新开一局 | 点「重新开始」，或按键盘 `Esc` |
| 清台结算 | 把所有图标球都撞进袋子后，会弹出本局用时、入袋数、击球次数和平均每颗用时 |

### 小规则

- 白球自己掉进袋子不会扣分，会自动摆回台面空位；
- 一局固定 15 颗图标球，从第一杆击出开始计时；
- 球停下来之后才能打下一杆，球还在滚的时候按鼠标不会出杆。

## 功能一览

- 真实感的台球物理：滚动摩擦、库边反弹、球与球弹性碰撞
- 三段式瞄准辅助线（出球 / 反弹 / 被撞球方向）
- 力度条蓄力，力度大小自己控制
- 本局用时、已入袋、剩余球数、击球次数实时统计
- 清台结算卡片：总用时、入袋数、击球数、平均每颗用时
- 响应式布局，窄屏手机上也能正常摆台
- 单文件自包含，无任何外部依赖、无第三方脚本

## 隐私说明

- 游戏**只在你自己的浏览器里运行**，图标是程序内置的示意图案，不会去读取你桌面上的真实图标、文件名或截图；
- 不联网、不上传任何成绩或设备信息；
- 没有账号、没有排行榜、没有埋点统计。

## 遇到问题怎么反馈

玩的时候如果遇到球卡住、画面错位、击球没反应、手机上显示不正常，欢迎提 Issue：

1. 打开仓库的 **Issues** 标签页，点 **New issue**；
2. 说清楚你用的是什么设备和浏览器（例如「Windows 11 + Chrome 131」「iPhone + Safari」）；
3. 描述一下操作到哪一步出的问题，最好附一张截图；
4. 如果是报错，把页面里或控制台里的错误文字一起贴上来。
